## 📌 Project Overview
This project predicts whether a customer is eligible for a personal loan based on financial and demographic details using Machine Learning techniques.  
It simulates a real-world banking decision support system.

## 🎯 Objective
To assist banks in identifying potential loan customers by analyzing income, education, credit behavior, and account details.

## 🛠️ Tech Stack
- Python
- Pandas
- NumPy
- Scikit-learn
- Google Colab
- GitHub

## 📊 Dataset
Synthetic dataset modeled after the Kaggle *Bank Personal Loan Modelling* dataset.  
The dataset maintains realistic financial correlations.

## 🤖 Machine Learning Models
- Logistic Regression (baseline, explainable)
- Decision Tree Classifier (rule-based decision making)

## ⚙️ Workflow
1. Data loading and preprocessing  
2. Feature selection and scaling  
3. Model training and evaluation  
4. Accuracy and confusion matrix analysis  
5. Loan eligibility prediction

## 📈 Results
- Models achieved meaningful accuracy
- Decision Tree captured non-linear patterns
- Logistic Regression provided stable baseline predictions
